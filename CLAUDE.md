# CLAUDE.md — Project Me Club · Новорічний сайт 2027

Новорічний сайт-подарунок для учасників Project Me Club (ТЗ — `site idea.txt`, у git не потрапляє).
Головна механіка: випадкове передбачення на 2027 рік. Довкола — міні-ігри, стіна побажань, окремі сторінки.

- Живий сайт: https://kuhciob.github.io/Advent/ (GitHub Pages з гілки `main`, корінь репозиторію)
- Репозиторій: https://github.com/kuhciob/Advent (remote `https://kuhciob@github.com/kuhciob/Advent.git`)
- Користувач спілкується українською — відповідай українською.

## Стек і принципи

- Чистий HTML + CSS + JS (ES5-стиль, IIFE, `'use strict'`), **без збірки, без фреймворків, без npm-залежностей**.
- Бекенду немає. Винятки — Google Таблиці через Google Apps Script: «Стіна побажань» (`tools/wishes-backend.gs`, URL у `js/wall.js` → `WISHES_API_URL`) і адвент-календар (`tools/advent-backend.gs`, URL у `advent/js/advent.js` → `ADVENT_API_URL`).
- **Контент адвенту в репозиторій не комітити** (репозиторій публічний): експорт з Notion і `private/` — у `.gitignore`, тексти живуть лише в Google Таблиці.
- Особисті дані користувачів **ніколи** не надсилаються на сервер — лише `localStorage` + експорт/імпорт файлом.
- Дані, які редагує людина, — окремими JSON у `data/` (передбачення, бонуси).
- Mobile-first; перевіряти 320, 390 і 1440 px; без горизонтального скролу.
- Поважати `prefers-reduced-motion` (на машині користувача анімації Windows вимкнені — сайт показує спокійну версію, це не баг).
- Усі `localStorage`-операції — у `try/catch` з запасним варіантом у пам’яті.
- Користувацький текст виводити тільки через `textContent` (ніякого `innerHTML` з даних користувачів).

## Структура

```
index.html                 головна (усі екрани: intro, loading, result, games, memory, catcher, scratch, wall)
css/style.css              спільні стилі й токени (кольори, шрифти, .btn, .card, .link-btn, .game-head, футер…)
js/effects.js              canvas-небо: сніг, зірки, window.Sky.burst(x, y, {count, power})
js/app.js                  логіка головної: передбачення, навігація екранів, відлік у футері, window.PMC.{shareText, toast}
js/game.js                 «Знайди пару»      → window.MemoryGame
js/catcher.js              «Зірколов»         → window.StarCatcher
js/scratch.js              «Скретч-картка»    → window.ScratchCard
js/wall.js                 «Стіна побажань»   → window.WishWall
data/predictions.json      130 передбачень (ціль — 500), перевірка: python tools/check_predictions.py
data/bonuses.json          36 бонусів для скретч-картки
tools/wishes-backend.gs    Apps Script для стіни побажань
tools/advent-backend.gs    Apps Script адвенту (віддає комірки лише після відкриття за Києвом)
tools/advent_import.py     Notion-експорт → private/advent-content.csv (+ .local.json для тестів)
advent/                    сторінка адвент-календаря (index.html, css/advent.css, js/advent.js, js/richtext.js)
assets/                    logo.png (прозорий), favicon, og-image.png
```

Окремі сторінки (якщо з’являться) живуть у власній папці (`<назва>/index.html`) і підключають `../css/style.css`, `../js/effects.js` та свої файли. `js/app.js` на окремих сторінках **не підключати** — він розрахований на розмітку головної.

## Бренд і дизайн

- Основні кольори: темно-синій `#09346f` і білий (як на логотипі). Акценти: золото `#d6ba8b` / `#f1dcae`, бордо `#4a1733` / `#6b1e40`, крем `#f5eee1`. Усе — CSS-змінні в `:root` у `css/style.css`.
- Шрифти: Roboto Slab (заголовки, цифри) + Manrope (текст), Google Fonts з кирилицею.
- Фірмовий прийом: біла цифра/літера + синя «щілина» + золота тінь (`text-shadow`), як у літери P на логотипі.
- Стиль — «старий університет взимку»: нічне небо, сніг, кремові картки з подвійною рамкою, сургучна печатка. Не дитячий новорічний дизайн.

## Тексти (важливо)

- Звертання на **«ти»**.
- **Гендерно-нейтрально**: жодних форм минулого часу чи прикметників із родом щодо читача («ти зробив/зробила», «готовий», «сам»). Переформульовувати («коли відчуєш, що час», «мені хотілося б», «людина» замість «він/вона»).
- Без негативу, страхів, гарантій («гарантовано», «обов’язково»), без прив’язки до конкретних дат/подій.
- «Святий Миколай», не «Дід Мороз».
- Апостроф `’`, лапки «ялинки», вкладені лапки „…“.
- Назва бренду в текстах: «Project Me Club» або «project.me.club».

## Кеш і версії файлів

GitHub Pages кешує файли до 10 хв. У кожному HTML до CSS/JS дописано `?v=РРРРММДДNN`.
**Після будь-якої зміни CSS/JS — підняти версію в усіх посиланнях відповідного HTML** (головна: `index.html`; окремі сторінки — свої). Інакше браузер змішає нову сторінку зі старими скриптами (вже траплялося: «вічне» перемішування, мертві посилання).

## Перевірка

- Локальний сервер: `python -m http.server 8765 --bind 127.0.0.1` у корені (або `start-local.cmd`). Через `file://` сайт не працює (fetch JSON).
- Браузерні тести — headless Edge (`C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe --headless=new --remote-debugging-port=…`) через CDP з Node (у Node є глобальний `WebSocket`). Для анімацій емулювати `prefers-reduced-motion: no-preference`. Скрипти тестів тримати в scratchpad, не в репозиторії.
- Python 3.12 + Pillow доступні. У bash heredoc з українськими лапками/апострофами інколи ламається — довші скрипти писати у файл інструментом Write.

## Git і деплой

- Комітити й пушити **лише коли користувач просить**. Коміт-повідомлення англійською, з трейлером `Co-Authored-By`.
- Після пушу Pages публікує ~1 хв; перевіряти, що живий HTML містить нову `?v=…`.
- Після публікації нагадати користувачу оновити сторінку з Ctrl+F5.

## Паралельна робота кількох сесій

Щоб не перетирати чужі зміни:
- **Self Date** — окремий сайт в окремому репозиторії (локально `../SelfDate`), у цьому репозиторії його файлів немає й не має бути.
- Нову сторінку роби у **власній папці** з власними `css/<назва>.css`, `js/<назва>.js`, `data/<назва>.json`.
- Спільні файли (`css/style.css`, `index.html`, `README.md`, `CLAUDE.md`) змінюй мінімально і точково (Edit, не перезапис цілого файлу); перед комітом — `git pull --rebase`, щоб підхопити роботу іншої сесії.
- Посилання на нові сторінки з головної — у блоці `.extra-links` (головний екран і під карткою передбачення).
