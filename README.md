# Project Me Club · Передбачення на 2027

Новорічний сайт-подарунок для учасників клубу: натискаєш кнопку й отримуєш випадкове передбачення на 2027 рік.
Без реєстрації та платних сервісів: це звичайні статичні файли. Єдине, що зберігається спільно для всіх, — «Стіна побажань» (безкоштовно, у Google Таблиці).

## Структура

```
index.html                 розмітка всіх трьох екранів
css/style.css              стилі (кольори задані змінними на початку файлу)
js/app.js                  логіка: вибір без повторів, екрани, «Поділитися»
js/effects.js              сніг, зірки, золоті іскри (canvas)
js/game.js                 міні-гра «Знайди пару» (іконки, ходи, час, рекорд у localStorage)
js/catcher.js              міні-гра «Зірколов» (canvas, 30 секунд, рекорд у localStorage)
js/scratch.js              міні-гра «Скретч-картка» (стирання інею, бонуси без повторів)
js/wall.js                 «Стіна побажань» (форма + дошка стікерів; адреса бекенду — WISHES_API_URL)
data/predictions.json      база передбачень (редагується вручну)
data/bonuses.json          бонуси для «Скретч-картки»: типи (заголовок + іконка) і 36 бонусів
assets/                    логотип, favicon, картинка-прев'ю og-image.png
tools/check_predictions.py перевірка бази
tools/wishes-backend.gs    бекенд «Стіни побажань» для Google Apps Script
start-local.cmd            локальний запуск у Windows
```

## Як переглянути локально

Сайт завантажує `predictions.json` через `fetch`, тому подвійний клік по `index.html` **не спрацює**: браузер блокує читання файлів через `file://`.

- **Windows:** подвійний клік по `start-local.cmd` (потрібен Python). Сайт відкриється на http://localhost:8080
- **Будь-де:** `python -m http.server 8080` або `npx serve` у папці проєкту.

## Як редагувати передбачення

Файл `data/predictions.json`, масив `predictions`:

```json
{ "id": 31, "category": "it", "text": "Текст передбачення." }
```

- `id` має бути унікальним числом. Нові передбачення можна просто дописувати в кінець.
- `category` береться з переліку `categories` у тому ж файлі. На сайті категорія не показується, вона потрібна лише для балансу.
- Апостроф у текстах — `’`, лапки — «ялинки».
- Пишемо без родових форм («ти зробив/зробила»), бо передбачення має пасувати кожному.

Після змін запусти перевірку:

```
python tools/check_predictions.py
```

Вона знаходить дублікати, схожі тексти, задовгі фрази, заборонені формулювання («гарантовано», «на тебе чекає успіх»…), можливі родові форми й конкретні дати.

## Як працює «без повторів»

Переглянуті `id` зберігаються в `localStorage` браузера (ключ `pmc2027:seen:v1`). Поки не показано всю базу, передбачення не повторюються, зокрема й після закриття та повторного відкриття сайту. Коли база вичерпана, починається нове коло, і щойно показане передбачення першим не випаде.
Якщо до бази додати нові передбачення, вони автоматично потраплять у ще не переглянуті.

## Зворотний відлік

На головному екрані показано відлік до 1 січня 2027, 00:00 за місцевим часом відвідувача. Опівночі блок змінюється на «З Новим 2027 роком! 🎉» (з іскрами), а статус — на «Твій 2027 уже запущено 🚀». Дата задана константою `NEW_YEAR` у `js/app.js`.

## Стіна побажань

Учасники пишуть побажання прямо на сайті, а вони зберігаються у твоїй Google Таблиці. Таблицю не публікуємо: сайт спілкується з нею через невеликий скрипт Google Apps Script.

Поки скрипт не підключено, стіна працює в **демо-режимі**: показує кілька прикладів, а нові побажання бачить лише автор (у своєму браузері).

### Підключення (≈10 хвилин, один раз)

1. Створи нову Google Таблицю (наприклад, «Стіна побажань 2027»).
2. У таблиці: **Розширення → Apps Script**.
3. Видали вміст файлу `Code.gs`, встав увесь код із `tools/wishes-backend.gs`, натисни **Зберегти** 💾.
4. **Розгорнути → Нове розгортання** → шестерня → **Вебзастосунок**:
   - *Опис*: будь-який;
   - *Виконувати від імені*: **Я**;
   - *Хто має доступ*: **Будь-хто**.
5. **Розгорнути** → Google попросить дозволи (це твій власний скрипт; якщо з'явиться «Google не перевірив цей застосунок» → *Додатково* → *Перейти до …*).
6. Скопіюй **URL вебзастосунку** (закінчується на `/exec`).
7. У файлі `js/wall.js` встав його в рядок `var WISHES_API_URL = '';`, зміни версію `?v=…` в `index.html` і запуш.

Аркуш «Побажання» створиться автоматично з першим побажанням.

### Модерація

- Колонка **«Сховати»** — постав галочку, і побажання зникне зі стіни (протягом хвилини).
- Хочеш спершу схвалювати кожне побажання — у скрипті зміни `PREMODERATION = false` на `true`; тоді на стіні будуть лише рядки з галочкою **«Показати»**.
- Після будь-якої зміни коду скрипта: **Розгорнути → Керувати розгортаннями → ✏️ → Версія: нова → Розгорнути** (URL не зміниться).

Вбудований захист: обмеження довжини (200 символів, ім'я — 40), базовий фільтр лайки на сайті та в скрипті, пауза 30 с між побажаннями з одного браузера, загальний ліміт 30 побажань за хвилину, прихована «пастка» для ботів. Тексти на сайті виводяться лише як текст (без HTML).

## Адвент-календар (`advent/`)

Будинок із 24 вікнами: щодня за київським часом «запалюється» нове вікно-комірка. Прогрес (які комірки переглянуто) зберігається в браузері.

**Контент не лежить у репозиторії** (він публічний). Тексти — у закритій Google Таблиці, а Apps Script (`tools/advent-backend.gs`) віддає текст комірки лише після її відкриття. Час перевіряє сервер, тож переведений годинник на телефоні нічого не відкриє.

### Підключення (один раз)

1. Експортуй контент-план з Notion у Markdown, поклади файл у корінь (він у `.gitignore`) і запусти
   `python tools/advent_import.py "Year Wrap ....md"` → з’явиться `private/advent-content.csv` (папка `private/` у git не йде).
2. Створи нову Google Таблицю (доступ лише для команди) → Розширення → Apps Script → встав `tools/advent-backend.gs` → збережи.
3. Обери функцію `setup` → «Виконати». У «Журналі виконання» буде **ключ тестування** — збережи його, у код не вставляй.
4. Відкрий аркуш «Адвент» → Файл → Імпорт → Завантажити → `private/advent-content.csv` → «Замінити поточний аркуш».
5. Розгорнути → Нове розгортання → «Вебзастосунок» (виконувати від імені: «Я», доступ: «Будь-хто») → скопіюй URL `…/exec` у `advent/js/advent.js` → `ADVENT_API_URL`.

### Колонки аркуша «Адвент»

| Колонка | Що це |
| --- | --- |
| `day` | номер комірки (1–24) |
| `opens` | коли відкривається, київський час: `2026-12-05 00:00` |
| `type` | іконка у відчиненому вікні: `promo`, `raffle`, `video`, `prompts`, `wallpaper`, `special`, `gift` |
| `title` | заголовок у вікні комірки (необов’язково) |
| `logo` | посилання на логотип партнера — показується у відчиненому вікні (необов’язково) |
| `cover` | `TRUE` — подарунок спершу «загорнутий», треба натиснути, щоб розгорнути |
| `body` | текст із колонки «Повідомлення в чаті клубу» |
| `status` | `active` — розіграш триває, `finished` — завершено |
| `winner` | ім’я переможця (підставляється замість `{winner}`) |
| `result` | текст оголошення переможця — показується, коли `status = finished` |
| `hidden` | `TRUE` — сховати комірку, навіть якщо час настав |
| `note` | внутрішні нотатки, на сайт не віддаються |

Розмітка в `body` і `result`: `**жирний**`, `__курсив__`, `||прихований текст||` (як спойлер у Telegram), `[текст](посилання)`, `[[copy:КОД]]` — кнопка копіювання, `[[copy:ТЕКСТ|Підпис]]` — кнопка з підписом. Окремим рядком: `[[button:Підпис|посилання]]` — велика кнопка, `![опис](посилання)` — зображення (посилання Google Drive теж працюють, якщо файл відкрито для перегляду). Рядки з `•`, `-`, `—`, `1.` стають списками.

Зміни в Таблиці з’являються на сайті самі за ~30 секунд, без деплою.

### Тестування до запуску

- `…/advent/?preview=КЛЮЧ` — усі комірки відкриті (жовта смужка вгорі; прогрес окремо від справжнього).
- `…/advent/?preview=КЛЮЧ&at=2026-12-05T10:00` — як сторінка виглядатиме 5 грудня о 10:00.
- Локально без Таблиці: `start-local.cmd` → `http://127.0.0.1:8765/advent/?preview` (бере `private/advent.local.json`).
- Посилання на конкретну комірку: `…/advent/#5` (відкриється, якщо комірка вже доступна).

## Анімації та доступність

Якщо в системі ввімкнено «зменшення руху» (Windows: *Параметри → Спеціальні можливості → Візуальні ефекти → Ефекти анімації* вимкнено; iOS: *Зменшення руху*), сайт показує спокійну версію без снігу та перемішування карток. Це навмисно.

## Оновлення сайту і кеш браузера

GitHub Pages дозволяє браузерам до 10 хвилин тримати файли в кеші. Щоб після оновлення нова сторінка не змішувалася зі старими скриптами, у `index.html` до CSS і JS дописано версію: `style.css?v=2026111606`. **Після змін у CSS/JS заміни це число на нове** (в усіх місцях, де воно трапляється) — тоді браузери завантажать свіжі файли. Базу `predictions.json` браузер і так щоразу перевіряє на сервері.

## Розміщення на безкоштовному хостингу

Підійде будь-який статичний хостинг: просто завантажити вміст папки (без `imgs/` і `tools/`).

- **Netlify Drop**: перетягнути папку на https://app.netlify.com/drop
- **GitHub Pages**: репозиторій → Settings → Pages → гілка `main`, папка `/`.
- **Cloudflare Pages** / **Vercel**: так само, без кроку збірки.

**Після розміщення** заміни в `index.html` відносний шлях у `og:image` на повну адресу (наприклад, `https://назва.netlify.app/assets/og-image.png`) і додай `og:url`. Тоді в Telegram і Viber посилання показуватиметься гарною карткою.
