# Project Me Club · Передбачення на 2027

Новорічний сайт-подарунок для учасників клубу: натискаєш кнопку й отримуєш випадкове передбачення на 2027 рік.
Без бекенду, реєстрації та платних сервісів: це звичайні статичні файли.

## Структура

```
index.html                 розмітка всіх трьох екранів
css/style.css              стилі (кольори задані змінними на початку файлу)
js/app.js                  логіка: вибір без повторів, екрани, «Поділитися»
js/effects.js              сніг, зірки, золоті іскри (canvas)
js/game.js                 міні-гра «Знайди пару» (іконки, ходи, час, рекорд у localStorage)
js/catcher.js              міні-гра «Зірколов» (canvas, 30 секунд, рекорд у localStorage)
data/predictions.json      база передбачень (редагується вручну)
assets/                    логотип, favicon, картинка-прев'ю og-image.png
tools/check_predictions.py перевірка бази
start-local.cmd            локальний запуск у Windows
```

## Як переглянути локально

Сайт завантажує `predictions.json` через `fetch`, тому подвійний клік по `index.html` **не спрацює**: браузер блокує читання файлів через `file://`.

- **Windows:** подвійний клік по `start-local.cmd` (потрібен Python). Сайт відкриється на http://localhost:8080
- **Будь-де:** `python -m http.server 8080` або `npx serve` у папці проєкту.

## Як редагувати передбачення

Файл `data/predictions.json`, масив `predictions`:

```json
{ "id": 31, "category": "it", "text": "Текст передбачення." }
```

- `id` має бути унікальним числом. Нові передбачення можна просто дописувати в кінець.
- `category` береться з переліку `categories` у тому ж файлі. На сайті категорія не показується, вона потрібна лише для балансу.
- Апостроф у текстах — `’`, лапки — «ялинки».
- Пишемо без родових форм («ти зробив/зробила»), бо передбачення має пасувати кожному.

Після змін запусти перевірку:

```
python tools/check_predictions.py
```

Вона знаходить дублікати, схожі тексти, задовгі фрази, заборонені формулювання («гарантовано», «на тебе чекає успіх»…), можливі родові форми й конкретні дати.

## Як працює «без повторів»

Переглянуті `id` зберігаються в `localStorage` браузера (ключ `pmc2027:seen:v1`). Поки не показано всю базу, передбачення не повторюються, зокрема й після закриття та повторного відкриття сайту. Коли база вичерпана, починається нове коло, і щойно показане передбачення першим не випаде.
Якщо до бази додати нові передбачення, вони автоматично потраплять у ще не переглянуті.

## Зворотний відлік

На головному екрані показано відлік до 1 січня 2027, 00:00 за місцевим часом відвідувача. Опівночі блок змінюється на «З Новим 2027 роком! 🎉» (з іскрами), а статус — на «Твій 2027 уже запущено 🚀». Дата задана константою `NEW_YEAR` у `js/app.js`.

## Анімації та доступність

Якщо в системі ввімкнено «зменшення руху» (Windows: *Параметри → Спеціальні можливості → Візуальні ефекти → Ефекти анімації* вимкнено; iOS: *Зменшення руху*), сайт показує спокійну версію без снігу та перемішування карток. Це навмисно.

## Розміщення на безкоштовному хостингу

Підійде будь-який статичний хостинг: просто завантажити вміст папки (без `imgs/` і `tools/`).

- **Netlify Drop**: перетягнути папку на https://app.netlify.com/drop
- **GitHub Pages**: репозиторій → Settings → Pages → гілка `main`, папка `/`.
- **Cloudflare Pages** / **Vercel**: так само, без кроку збірки.

**Після розміщення** заміни в `index.html` відносний шлях у `og:image` на повну адресу (наприклад, `https://назва.netlify.app/assets/og-image.png`) і додай `og:url`. Тоді в Telegram і Viber посилання показуватиметься гарною карткою.
